# Contest Tracker

A web application that helps competitive programmers discover upcoming coding contests, save contests for later, and track their Codeforces profile from a single dashboard.

## Features

### Contest Dashboard
- View upcoming contests from multiple platforms
- Search contests by name or platform
- Filter contests by platform
- Card View and Table View
- Contest countdowns
- Direct links to contest pages

### My Contests
- Save contests for later
- View all saved contests in one place
- Remove saved contests
- Persistent storage using Local Storage

### Rating Tracker
- Track Codeforces handles
- View current rating
- View maximum rating
- View rank
- Save and manage handles

### Other Features
- Responsive design
- Retro-inspired UI
- Privacy Policy page
- Fast client-side filtering

## APIs Used

### Clist API
Used to fetch upcoming contests from multiple competitive programming platforms.

Platforms supported:
- Codeforces
- LeetCode
- CodeChef
- AtCoder
- Kaggle

### Codeforces API
Used for:
- User profile information
- Rating
- Maximum Rating
- Rank
